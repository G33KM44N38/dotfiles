# Natural Chat Continuation

Before drafting a message into an existing conversation:

1. Read the recent conversation first.
2. Continue the current flow. Do not reset the exchange or make it feel like a new conversation if the thread is already active.
3. Avoid greetings like "coucou", "hello", or "salut" when the thread is already active.
4. Match the user's last tone, language, formality, rhythm, punctuation, typo tolerance, and message length from that specific conversation.
5. Keep it short and direct unless the conversation already calls for detail.
6. Ask only the missing thing. Do not re-explain context the recipient already has.
7. For WhatsApp specifically, draft as if the user is continuing exactly where they left off: casual, contextual, and minimally polished unless the user's recent messages were polished.

For appointment clarification messages, reference the known details naturally:

```text
Pour le rendez-vous de Naima le 22 juillet à 19h30, tu voulais quelle option pour les Fulani Braids : carré, mi-dos, bas du dos ou longue ? Et en M ou S/M ?
```

Only send after explicit confirmation when the sending workflow requires it.

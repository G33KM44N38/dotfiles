# Global instruction catalog

One job: route global tasks to the smallest relevant instruction set.

## Files

- `render.md`: Render CLI access and credential checks.
- `github.md`: GitHub, pull requests, reviews, stacks, and proof artifacts.
- `tracking.md`: Linear scope and shared issue proposals.
- `deletion.md`: Safe deletion and cleanup.
- `apple-platforms.md`: macOS and iOS application identity.
- `computer-use.md`: Explicit authorization for computer use.
- `worktrees.md`: Repository and worktree isolation.
- `herdr.md`: Herdr navigation and Codex agent launches.
- `personal-ops.md`: Status work, planning, ownership, monitoring, and calendars.
- `keyboard.md`: Shared keyboard intent, device profiles, Corne roles, and flashing.
- `engineering-values.md`: Design judgment, simplicity, and scope.

## Loading rule

Read only the files that match the current task. Read all matching files when a task spans several domains.

The user's explicit instructions take precedence over the defaults in these files.

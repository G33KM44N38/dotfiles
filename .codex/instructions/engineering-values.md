# Engineering values

One job: guide architecture, scope, and implementation choices.

## Kylian's preferences

- Prefer ambitious ideas, simple systems, and software that feels obvious.
- Do not preserve complexity only because it exists.
- Do not add machinery because it looks impressive.
- Understand the real constraint.
- Choose the smallest model that makes correct behavior unsurprising.
- Measure twice and cut once.
- Apply YAGNI and resist scope creep.
- Honor the developer's intent in a minimal, realistic way.

Treat these instructions as strong defaults. The developer's explicit preferences can override them.
